# NexPulse Frontend

The React client for NexPulse — a landing page that signs users in with Google
through Firebase.

This is a short pointer. The full walkthrough lives in the docs:

- **[Frontend guide](../docs/frontend/README.md)** — folder structure, the login
  flow end to end, Redux and routing, design system, environment variables.
- **[Getting Started](../docs/getting-started.md)** — how to run the whole stack.
- **[Tools](../docs/concepts/tools.md)** — every library, explained.

## Quick start

```bash
npm install
npm run dev
```

Vite prints the address (usually `http://localhost:5173`). It needs the backend
running too — see [Getting Started](../docs/getting-started.md).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server with hot reload. |
| `npm run build` | Produce an optimized build in `dist/`. |
| `npm run preview` | Serve the production build locally. |
| `npm run lint` | Run ESLint over the code. |
